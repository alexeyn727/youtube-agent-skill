# YouTube-агент для Claude — русская версия

Форк [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill)
с поддержкой русского языка. Одиннадцать скиллов Claude для ведения YouTube-канала. Бесплатно,
лицензия MIT, без регистрации и API-ключей.

Скиллы работают на двух языках: английский ведёт себя ровно как в оригинале, а русский текст
скрипты распознают сами — по кириллице.

**Ничего не публикуется без вас.** Скиллы пишут, загружаете вы.

## Что добавлено для русского

| Где | Что |
| --- | --- |
| `hooks.json` | У всех 21 формулы хука есть русское название, описание, пример, условие провала и шаблоны `match_ru` |
| `hookscore.py` | Русские слова-паразиты, «пустые» прилагательные, обращение на «ты/вы», ставки и интрига; длина хука 7–20 слов; отчёт по-русски |
| `title.py` | Русские «пустые» и служебные слова, повтор обложки и заголовка по основе слова, сообщения по-русски |
| `deadair.py` | Русские слова-паразиты: «эм», «ну вот», «короче», «типа», «в общем», «как бы», «это самое» |
| `chapters.py` | Русские служебные слова и сравнение по основе, поэтому черновые названия глав — настоящие слова, а не `Section` |
| `retention.py` | Выгрузка из русской локали: разделитель «;» и числа «45,3» — раньше 45,3% читалось как 453% |
| `swipe.py` | Узнаёт формулу в русских заголовках |
| все `SKILL.md` | Русские фразы-триггеры и раздел «Русский язык» |
| `templates/voice.ru.md` | Шаблон голоса на русском |

Во всех скриптах вывод идёт в UTF-8, а файлы открываются в UTF-8, поэтому в консоли Windows нет
кракозябр и нет падений на кириллице.

## Установка

В Claude Code (это команды чата Claude, а не терминала):

```
/plugin marketplace add alexeyn727/youtube-agent-skill
/plugin install youtube-agent
```

Или вручную:

```bash
git clone https://github.com/alexeyn727/youtube-agent-skill.git
cp -r youtube-agent-skill/skills/yt-* ~/.claude/skills/
mkdir -p ~/.claude/youtube && cp youtube-agent-skill/templates/voice.ru.md ~/.claude/youtube/voice.md
```

Затем заполните `~/.claude/youtube/voice.md` или пришлите Claude три своих ролика со словами
«составь мой voice.md по ним».

На Windows Python обычно вызывается как `python`, а не `python3`: скиллы знают об этом.

## Одиннадцать команд

| Команда | Что делает |
| --- | --- |
| `/yt-script` | Сценарий из идеи: пять хуков по 21 формуле с оценкой, затем текст с отметками удержания |
| `/yt-package` | Заголовок и обложка как одна пара, с проверкой на обрезку, повторы и пустые слова |
| `/yt-edit` | Список правок монтажа по расшифровке: паузы, паразиты, дубли, с таймкодами |
| `/yt-comment` | Сортирует комментарии на четыре группы, пишет ответы вашим голосом, подсказывает, что закрепить |
| `/yt-plan` | План на неделю под ваше реальное время: один главный ролик, один лёгкий, три шортса |
| `/yt-viral` | Что работает в нише — по тому, во сколько раз ролик обогнал медиану своего канала |
| `/yt-retention` | Разбор выгрузки удержания: утечка на хуке, обрывы и сползание |
| `/yt-shorts` | Шортсы, которые уже есть внутри длинного ролика, с новой первой фразой |
| `/yt-seo` | Описание, теги и три поисковых запроса, которые ролик должен выигрывать |
| `/yt-chapters` | Главы по расшифровке с проверкой правил YouTube |
| `/yt-audit` | Разбор всего канала с одним главным исправлением вместо двадцати |

## Честно о русской версии

- Русские списки слов и шаблоны — перевод английской эвристики. Оригинал откалиброван на 74 реальных
  англоязычных хуках, русскую версию на реальных русских роликах отдельно не калибровали. Низкий балл
  — повод перечитать, высокий — не обещание.
- Основа слова — грубая (первые пять букв). Она спасает от падежей, но иногда склеивает разные слова.
- Скрипты сравнивались с оригиналом на одних и тех же английских входных данных — вывод совпадает
  байт в байт, то есть английское поведение не изменилось.

## Обновления из оригинала

```bash
gh repo sync alexeyn727/youtube-agent-skill
```

Русские изменения сделаны добавлением полей и веток, поэтому конфликты при слиянии с оригиналом
маловероятны, но возможны в тех же местах скриптов.
